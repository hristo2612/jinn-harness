# Text Chat: actual partials, completed context and honest recovery

UI-6a mounts Chat over the existing session API and UI moments. The public arc
amendment and the seam READMEs own scope and configuration. The unchanged kernel
pin is `f8b285b5aaffddeeb4939a0035d6c18a03487999`; this packet changes no kernel,
vendor surface, lock for a guest, toolchain or production profile.

The existing exec codec has completed messages only. A native red probe fed
`item/agentMessage/delta` and got `[]` instead of `[Delta { text: "Hello" }]`.
The opt-in app-server codec now uses installed codex-cli 0.153.4 schemas and
actual stdio protocol. Dedicated HOME/CODEX_HOME, an empty workspace and a bounded
environment prevent shared agent config from entering the turn. Effective config,
MCP status, model/effort and instruction sources are checked before the prompt.
Feature controls deny shell/code execution, web, apps, hooks, skills and tools.
Unexpected approval requests and tool-call frames fail the turn honestly.

Initial real synthetic protocol proof (before broad implementation): first
partial at 7.609 seconds, completion at 40.512 seconds. A tool-demand probe
produced no canary write; the CLI reported `code-mode host is disabled` for the
attempt. Interrupt after two deltas returned `interrupted` and its owned process
was reaped. The Rust codec then drove a separate real Astra/high turn:

Targeted codec gate: 26 tests passed, including fragmented reads, repeated token
text, duplicate completed records, terminal loss, oversized/malformed data,
identity/config refusal and unexpected server requests. The session red tests
showed an empty running snapshot answer and accepted context overflow. Their
implemented cases passed: the live answer and event watermark are captured
under one registry lock, and overflow refuses before a turn is minted. Completed
pairs are serialized into the next prompt; failed/partial turns remain visible
history and never pretend to be completed context.

Stop retains the live drive until the provider reports an ending. The Codex
mode confirms process exit after kill. An unreachable engine reports stop
unconfirmed, preserving the answer without claiming that the process stopped.
Completed/cancelled answers are journaled; restart interruption does not claim
durable partial text.

The browser cursor applies the actual flattened session event shape in sequence.
Repeated text is valid; only repeated sequence numbers are skipped. A gap,
malformed frame or terminal event causes authoritative reconciliation, and a
five-second snapshot watchdog catches a missing ending. Reads are abortable and
back off; a generation rejects late responses. A POST is never retried. An
ambiguous send keeps its draft/optimistic text and reads saved history before
another send. Before-send's folded text is the optimistic and stored identity.
The session title and creation metadata allow readback of uncertain creation.

The UI ports the source formatter and scroll arithmetic named in the arc.
The formatter is split at inline/block parsing boundaries to meet current lint
caps; two dormant legacy exemptions are removed, not activated by the new files. Stable
turn keys and memoized primitive message props isolate settled Markdown from
partial updates. Earlier pages use a measured visible-row anchor, including
Safari; upward reading detaches following, and Latest returns to the bottom.
The mobile detail owns its bottom edge and keyboard/safe-area clearance.

Web red-by-reversion: restoring the original root redirect fails the new provided
Chat route checks. Removing delta append fails the repeated-token, replay and
caught-up-ring cases (an omission mutation, not a claimed pre-edit red run).
The hook tests prove double-submit guarding, ambiguous-send retention, late
selection responses and stop uncertainty. The API tests prove direct SessionSpec
creation and refusal of unsupported folded identity/tools/attachments.

Verification evidence for the final head is recorded on the PR and packet,
including actual command tails. This note does not claim that an earlier build
proves later embedded web bytes. The opt-in `composition::text_chat` proof requires
a rebuilt ui-kit root and the archived pinned daemon; an absent vendor root is a
loud skip and cannot satisfy the packet's vendor acceptance.
